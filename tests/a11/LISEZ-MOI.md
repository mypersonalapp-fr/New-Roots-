# Tests de la leçon A1.1 (Playwright, Chromium 390×844)

Scripts écrits pendant la construction (octobre 2026). Ils servent à rejouer la leçon sans iPhone.
- act.py : grammaire, lecture, écoute. act2.py : expression, exercices. act3.py : Transversale + test de fin à 40/40.
- city.py : parcours des 6 missions Roots City. voice.py : micro simulé (mission 6). scroll.py : défilement conservé. mockups.py : captures annotées.

Utilisation : `python3 -m http.server 8000` à la racine du dépôt, puis `python3 tests/a11/<script>.py`.
Attention : certains scripts contiennent encore une chaîne de version `?v=AAAAMMJJx` à aligner sur celle du code (voir la doc d'intégration) et des chemins de sortie d'images à adapter.
